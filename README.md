# Telegram-юзербот: ИИ отвечает от вашего аккаунта

В отличие от обычного бота (BotFather), этот клиент входит в **ваш личный
аккаунт** через MTProto и отвечает вашим именем в выбранных вами чатах.
Провайдер ИИ на выбор: Anthropic Claude или Mistral AI.

> ⚠️ **Риски.** Автоматизация личного аккаунта нарушает условия сервиса
> Telegram и в теории может привести к ограничению аккаунта. Снижайте риск:
> держите белый список чатов минимальным, не шлите массово, сохраняйте
> «человеческую» паузу (`MIN_REPLY_DELAY`). Файл `*.session` = полный доступ
> к аккаунту — он в `.gitignore`, никогда не публикуйте его.

## Возможности
- Вход в ваш аккаунт по номеру телефона (код из Telegram, поддержка 2FA)
- Белый список чатов: ИИ отвечает **только** там (`ALLOWED_CHATS`), без него не запустится
- Режим «сразу»: ответ на входящее сообщение без ожидания
- Перехват: если вы ответили сами — ИИ замолкает в этом чате до следующего входящего
- Никогда не отвечает самому себе и на не-текст (стикеры/фото)
- Память диалога с сохранением на диск (`data/history.json`)
- Роль/характер задаётся в `prompt.txt` без правки кода
- Переключение Claude ↔ Mistral одной строкой в `.env`
- `ECHO_MODE=1` — проверка входа и фильтров без затрат на ИИ

## Структура
```
config.py     — загрузка и валидация .env
providers.py  — Claude / Mistral / echo (общий интерфейс)
memory.py     — память диалогов + сохранение на диск
main.py       — Telethon-клиент, авторизация, обработчики
prompt.txt    — системная роль (редактируется свободно)
```

## Установка

1. Получите `API_ID` и `API_HASH`: <https://my.telegram.org> → *API development tools*.
2. Ключ ИИ-провайдера: Claude — <https://console.anthropic.com/settings/keys>,
   Mistral — <https://console.mistral.ai/api-keys>.
3. Установите зависимости:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. Настройте `.env`:
   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```
   Обязательны: `API_ID`, `API_HASH`, `PHONE`, `ALLOWED_CHATS` и ключ провайдера.

## Запуск
```powershell
python main.py
```
При первом запуске в консоли появится запрос кода из Telegram (и облачного
пароля, если включена 2FA). После успешного входа создастся файл сессии —
дальше повторный ввод кода не нужен. Остановка — `Ctrl+C`.

### Проверка без затрат на ИИ
Поставьте `ECHO_MODE=1` в `.env` — юзербот будет отвечать эхом входящих
сообщений. Так проверяются вход, белый список и логика перехвата.

## Тесты
```powershell
python -m pytest -q
```
Тесты покрывают логику без сети и API-ключей: память, разбор конфига,
глушение чата владельцем, выбор провайдера.

## Белый список чатов
В `ALLOWED_CHATS` через запятую:
- `@username` — личные чаты и публичные группы;
- числовой `id` — любые чаты (для приватных групп id вида `-100…`).

Узнать id чата можно, переслав сообщение в [@userinfobot](https://t.me/userinfobot).

## Настройка роли
Откройте `prompt.txt` и опишите, как ИИ должен отвечать от вашего имени.
Изменения подхватываются при следующем запуске.
